# Jira Dashboard — Product Summary

## Vision

Provide Product/Project Managers and QA Leads with instant visibility into rework ratio — the effort spent fixing bugs relative to original development work.

## Target Audience

- Product/Project Managers
- QA Leads

## Core Features

- **Jira Cloud Integration** — Secure connection to fetch stories, tasks, and bugs
- **Rework Ratio Calculation** — Bug story points / original story points via "is caused by" links
- **Time Range Selector** — 30d, 60d, 90d filtering
- **Story/Task Breakdown** — Per-item rework ratio with sorting
